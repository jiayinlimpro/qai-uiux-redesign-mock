# QAI wireframes — layout references

Low-fidelity screenshots of the reviewed wireframes, one per screen, grouped by journey stage.
Screen IDs match `docs/03-navigation.md`.

## How to use (for Claude Code and developers)
- **Layout and placement only.** Use them for where things sit: panels, lists, tabs, buttons, banners.
- **Not visual design.** Colours, fonts and spacing come from `docs/08-design-system.md`.
- **Not data.** Names, counts and IDs in the screenshots may be older than the spec.
  The sample data in `docs/07-data-model.md` is the source of truth.
- **Default state only.** Interactive states (filters applied, collapsed sidebar, other tabs) are described in `docs/screens/`.
- If a screenshot and a doc disagree, **the doc wins**.
